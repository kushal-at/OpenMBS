# openmbs-desktop

Native 3D GUI workbench for OpenMBS built with `eframe` and `egui`.

## Features
- **3D Interactive Viewport**: Orbit, zoom, and pan around the 3D steel structural model, secondary members, and openings.
- **Parametric Inputs**: Building shape (span, eave heights, roof slope, unequal bays), ASCE 7-22 environmental hazard loads, member section catalogs, and costing rates.
- **Unit System Switching**: Instant toggle between US Imperial and SI Metric units.
- **Auto-Size Optimizer**: One-click frame sizing satisfying AISC 360-16 interaction ratios and drift limits.
- **Verification & Audit Viewer**: Direct in-app display of MBS Verify report, DBCHECK rule audit, BOMCHECK piece marks, and 3D clash detection.
- **Deliverables Exporter**: One-click generation of the full engineering bundle (IFC4, DXF, SVGs, CSVs, Manifest).
